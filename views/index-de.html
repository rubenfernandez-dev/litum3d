✨ Was ist eine Lithophanie?

Eine Lithophanie ist ein dreidimensionales Kunstwerk, das zum Leben erwacht, wenn Sie es beleuchten. Wenn Sie eine Lichtquelle dahinter platzieren, wird das Relief-Bild in Grautönen projiziert und erzeugt einen magischen und fesselnden Effekt. Es ist wie eine lebendige Leinwand, die sich mit der Lichtintensität verändert.

Perfekt, um emotionale Momente festzuhalten: ein Familienfoto, ein besonderes Porträt, eine Lieblingslandschaft. Jede Lithophanie ist einzigartig, weil sie mit IHREM Foto personalisiert ist.
